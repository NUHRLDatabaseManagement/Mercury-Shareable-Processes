# Prepending Application Notes
Need to prepend application notes without overwriting the existing field? This easy CDP will allow you to prepend application notes.

## Minimum Requirements
***
**Server Type:** Microsoft SQL

**Mercury Minimum Version:** 2021.4.8052 (This may work in 2021.3 but I have not tested it. It will not work prior to 2021.3 due to the need for custom dataset processes. 

**Skill Level:** Beginner. This is easily implementable Mercury Functionality and will assist you to prepend application notes Mercury Processes.

## Process Concept
***
This easy CDP will allow you to prepend application notes at the beginning of the application notes field without overwritting your exisitng data in the field.


## Mercury Installation
***

### Operation Installation
1. Download this file: [CDP - App Notes (Prepend) (Shareable).xml](assets/CDP%20-%20App%20Notes%20(Prepend)%20(Shareable).xml) (19 KB)

1. Import the operation into your Environment
   * Go to Setup -> Process -> Operations to begin. Follow the steps of the Import Wizard and be sure to **Save Changes** after completion. Note that you will be prompted to "*Create"* several objects.
